# OkuPic

送り先を選ぶだけで、写真を最適なサイズに自動調整するiOSアプリです。

## 機能

- **送り先プリセット** - LINE、X、Instagram、メルカリ、メール、Webに対応
- **自動リサイズ** - 送り先に合わせて解像度とファイルサイズを自動調整
- **メタデータ管理** - 位置情報やEXIF情報の確認・削除
- **カメラロール保存 / 共有** - 最適化した画像をそのまま保存・共有

## 動作環境

- iOS 17.6+
- iPhone / iPad対応

## 技術スタック

- SwiftUI
- PhotosUI
- ImageIO

## プライバシー

すべての画像処理はデバイス上でローカルに行われます。写真が外部サーバーに送信されることはありません。
